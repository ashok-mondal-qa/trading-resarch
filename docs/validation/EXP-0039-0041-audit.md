## Addendum, 2026-10-26: look-ahead found and fixed (spec v0.1.2)
Check 2 above missed a look-ahead in the data handling, not in the signals: the loader dropped each stock's bars
before its last adjustment error known by 2025-12-31. Those errors include real crashes (YESBANK −56% on
2020-03-06), so later crashers were invisible in earlier years; 660 of 2,205 adjusted stocks have an error.
Point-in-time handling now keeps all bars and only resets a stock's history after an error. Rerun once on dev
and validation: dev 2× CAGR fell from 14.8% / 24.9% / 18.7% to 13.4% / 16.7% / 15.1% (low vol / momentum /
mix), dev Sharpe from 1.09 / 0.99 / 1.13 to 0.98 / 0.77 / 0.95. Verdicts unchanged (all REJECTED; low vol and
the mix still fail only the interval check). The "extra finding" above about 2025 no longer holds: the mix
made +13% in 2025 after the fix. Lesson: a data-quality filter that uses the whole file is a look-ahead; check
every filter for the date it could have been known.
